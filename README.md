## 🚀 Quick Start

- Recommended: `npx tkp` opens the interactive menu — pick what you need.
- Common commands:

```bash
npx @tkp/cli i        # Full initialization: install + workflows + API/CCR + MCP
npx @tkp/cli u        # Update workflows only
npx @tkp/cli --lang zh-CN  # Switch interface language (example)
```

- Non-interactive example (provider preset):

```bash
npx @tkp/cli i -s -p 302ai -k "sk-xxx"
```

More usage, options, and workflows: see documentation.
