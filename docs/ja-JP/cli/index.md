# CLI コマンド概要

TKP の主要 CLI を一覧します。詳細は各ページを参照してください。

- `tkp init`：環境初期化、ワークフロー/テンプレート導入
- `tkp update`：テンプレート/ワークフロー/ツールの更新
- `tkp menu` (`npx tkp`)：インタラクティブメニュー
- `tkp ccr`：Claude Code Router の管理
- `tkp ccu`：利用状況 (ccusage) の表示
- `tkp config-switch` / `tkp cs`：複数設定の切り替え
- `tkp check-updates` / `tkp check`：アップデート確認
- `tkp uninstall`：選択的なアンインストール
